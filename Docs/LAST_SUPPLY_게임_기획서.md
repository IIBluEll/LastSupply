## 0. 결정 사항 요약

### 0.1 문서의 결정 수준

- **합의된 방향:** 포트폴리오가 제작 목적의 1순위이며, 전략적 깊이보다 운의 비중을 높인다. 작은 기본판을 완성한 뒤 콘텐츠와 기능을 확장한다.
- **기본판 기준 규칙:** 위 방향을 실제 플레이로 연결하기 위해 문서에서 채택한 설계다. 첫 구현은 이 규칙을 기준으로 하되, 플레이 결과와 후속 논의에 따라 변경할 수 있다. 모든 세부 규칙이 이전에 개별 합의되었다는 뜻은 아니다.
- **초기 테스트 값:** 일수, 확률, 보상, 피해, 초기 자원 등의 수치다. 구현 가능한 출발점이며, 재미나 난이도가 검증된 최종 밸런스가 아니다.
- **확장 후보:** 기본판 제작 범위에 포함하지 않는다. 후보에 적었다는 이유만으로 구현을 약속하거나 미리 시스템을 만들지 않는다.

파일명은 기존 문서 링크 유지를 위해 유지하고, 개정 버전은 문서 내부에서 관리한다.

### 0.2 기본 플레이 기준

| 항목 | 기본판 기준 규칙 |
|---|---|
| 세계관 | 좀비 아포칼립스, 소수 생존자가 거주하는 은신처 |
| 목적 | 제한 일수 안에 부품을 확보하여 무전기 수리 및 구조 요청 |
| 핵심 경험 | 주사위 결과를 기대하고, 우연한 사건에 대응하며, 한 번 더 탐색할지 결정 |
| 하루 행동 | 생존자 1명과 지역 1곳을 선택하여 하루 1회 탐색 |
| 단계 순서 | 진입 → 사건 발생 시 처리 → 수색 또는 수색 생략 → 다음 단계 / 귀환 |
| 주요 위험 감수 | 다음 단계로 진입하거나 선택형 사건의 보상을 노리는 결정 |
| 수색 | 단계당 최대 1회, 순수 D20, 버튼 한 번으로 굴림, 기본 비용·소음 없음 |
| 수색 보상 | 기본판은 지역 주 자원 한 종류. 처리 구조는 미발견·단일·복수 자원 보상을 같은 묶음으로 지원 |
| 사건 발생 | 단계 진입 시 내부 비공개 판정, 단계당 최대 1건 |
| 사건 처리 | 즉시 결과형 / 판정형 / 선택형 |
| 행동 판정 | D20 + 지정 능력치 보정 >= 난이도(DC) |
| 수색과 사건 | 별도 판정과 보상. 사건의 발생·성공 여부가 일반 수색 결과를 정하지 않음 |
| 귀환 | 소음에 따라 위험 발생 여부를 확인하고, 발생 시 사건 한 번으로 마무리 |
| 전리품 | 귀환 전까지 임시 보유. 사망 시 해당 탐색 전리품 전부 상실 |
| 식량 | 인원수와 무관하게 은신처 전체가 하루 일정량 소비 |
| 치료 | 출발 전 은신처에서 의약품 사용. 탐색 중 치료는 기본판에서 제외 |
| 시각 형태 | 2D 지역 일러스트 + 짧은 상황 설명 + 버튼 + 공통 주사위 연출 |

| 탐색 길이 | 최대 5단계 | 마지막 단계 처리 후 귀환 |
| 생존자 | 2명 | HP / 전투 / 기술, 6장 참조 |
| 초기 자원 | 식량 6 / 의약품 1 / 부품 0 | 모두 은신처 보유량 |
| 식량 소비 | 하루 2개 | 인원수와 무관, 게임 종료일에는 추가 정산 없음 |
| 식량 부족 | 살아 있는 생존자 전원 HP -2 | 부족한 날 한 번 적용, 부족 개수만큼 반복하지 않음 |
| 치료 | 의약품 1개로 HP +3 | 최대 HP까지만 회복 |
| 승리 부품 | 8개 | 귀환해 은신처에 반영된 부품 기준 |

확률·수색 보상은 4장, 귀환 위험은 5장, 이벤트 수치는 7장을 기준으로 한다. 문서에 기재된 캐릭터 이름과 모든 밸런스 수치는 초기 테스트용이다.

## 1. 게임 개요

### 1.1 기본 정보

| 구분 | 내용 |
|---|---|
| 가제 | **LAST SUPPLY** |
| 장르 | 운 중심 선택형 생존 탐색 / 캐주얼 익스트랙션 |
| 플랫폼 / 플레이 방식 | PC 우선 / 싱글 플레이 |
| 개발 환경 | Unity / C# |
| 그래픽 | 2D 일러스트 기반 UI 중심 |
| 제작 목적 | 완결된 게임 경험과 구현 의도를 설명할 수 있는 포트폴리오 |
| 첫 완성 목표 | 새 게임 → 은신처 → 탐색 → 귀환 → 정산 → 승리·패배 → 재시작 |

### 1.2 게임 콘셉트

좀비 아포칼립스 이후, 생존자들은 은신처에서 구조를 기다린다. 고장 난 무전기를 수리하려면 제한된 일수 안에 외부에서 부품을 확보해야 한다.

플레이어는 하루에 생존자 한 명을 파견한다. 주사위를 굴려 물자를 찾고, 뜻밖의 행운이나 위험 사건을 만난다. 더 들어가면 좋은 물자를 얻을 기회가 있지만, 다치거나 소음을 내면 귀환까지 위험해진다.

> **핵심 질문:** 지금 얻은 것을 가져갈까, 한 번만 더 굴려볼까?

정교한 전략으로 운을 제거하는 게임을 목표로 하지 않는다. 좋은 선택을 해도 실패할 수 있고, 무모한 탐색이 뜻밖의 성공으로 끝날 수도 있다. 다만 어떤 위험을 감수했는지는 플레이어가 이해할 수 있어야 한다.

### 1.3 설계 원칙

1. **운을 중심에 둔다.** 일반 수색에는 능력치 보정을 붙이지 않고, 사건 발생과 행동 성공도 확률에 영향을 받는다.
2. **선택의 수를 줄인다.** 출발 준비, 사건 대응, 계속 탐색/귀환에 집중한다. 모든 버튼에 전략적 고민을 요구하지 않는다.
3. **반복 조작을 짧게 만든다.** 수색 버튼에서 바로 주사위를 굴리고, 불필요한 굴리기 확인창은 넣지 않는다.
4. **위험과 결과는 이해할 수 있게 보여준다.** 내부 발생 판정값은 숨기지만, 행동의 대가·성공 조건·현재 귀환 위험은 표시한다.
5. **작은 기본판을 먼저 완성한다.** 실시간 전투, 맵 이동, AI, 복잡한 제작·시설 관리는 기본판에 포함하지 않는다.
6. **같은 규칙으로 콘텐츠를 늘린다.** 지역·사건·생존자를 추가할 때 기존 진행 순서를 재사용한다. 새 규칙이 필요한 확장은 별도로 판단한다.
7. **포트폴리오 설명은 실제 결과에 근거한다.** 완결된 플레이, UI 피드백, 콘텐츠 추가 방식, 처리한 예외를 보여준다. 계획만 있는 기능을 구현 실적으로 표현하지 않는다.

## 2. 승리와 패배

### 2.1 승리

- 살아 있는 생존자가 있고, 은신처에 확보한 부품이 목표량 이상이면 승리한다.
- 귀환 정산에서 부품을 반영한 직후 무전기 수리 및 구조 요청 연출을 실행한다.
- 별도 수리 주사위, 추가 날짜, 구조 대기전은 없다. 수리 비용은 목표량에 포함되며 추가 부품을 요구하지 않는다.
- 마지막 날에 가져온 부품도 인정한다. 목표를 일찍 달성하면 남은 날짜와 무관하게 종료한다.

### 2.2 패배

- 살아 있는 생존자가 없으면 전원 사망으로 패배한다.
- 마지막 날의 탐색 정산 후에도 목표를 달성하지 못하면 기한 초과로 패배한다.
- 첫 사망으로 바로 게임이 끝나지는 않는다. 다른 생존자가 남아 있고 기한이 남았다면 다음 날 계속한다.

### 2.3 전리품과 사망

- 일반 수색과 사건 보상은 모두 해당 탐색의 **임시 전리품**에 넣는다.
- 귀환 후 생존해 있으면 임시 전리품 전체를 은신처에 반영한다. 운반 한도는 기본판에 없다.
- 탐색 또는 귀환 도중 HP가 0이 되면 즉시 탐색을 종료하고 임시 전리품 전체를 잃는다. 남은 사건·수색은 진행하지 않는다.
- 사망한 생존자는 다시 파견하거나 치료할 수 없다. 은신처의 기존 자원과 다른 생존자는 해당 탐색 사망만으로 잃지 않는다.
- 체력과 자원은 0 미만으로 내려가지 않는다. 독립적인 즉사 판정은 기본판에 없다.

## 3. 하루 진행 구조

### 3.1 기본 루프

```text
하루 시작 / 은신처
    ↓
남은 날짜·목표 부품·생존자 상태 확인 / 치료(선택)
    ↓
생존자 1명과 지역 선택 → 출발
    ↓
외부 탐색 → 귀환 또는 사망
    ↓
전리품 정산 → 종료 조건 확인
    ↓
게임이 계속된다면 식량 소비 → 부족 피해 → 전원 사망 재확인
    ↓
다음 날
```

### 3.2 하루 행동

- 출발 시 그날의 탐색 기회를 사용한다. 조기 귀환하거나 사망해도 재출발할 수 없다.
- 출발하면 첫 단계에 바로 진입한다. 생존자·지역은 도중에 바꾸지 않는다.
- 기본판에는 탐색 없이 하루 넘기기, 대기 중 자동 회복, 여러 명 동시 파견이 없다.
- 은신처에서는 살아 있는 생존자를 선택해 치료할 수 있다. 의약품이 있으면 여러 번 사용할 수 있지만, 최대 HP인 대상에게는 사용하지 않는다.
- 출발 전에는 인물·지역 선택을 자유롭게 바꿀 수 있다. 출발 이후에는 결정이 적용된다.

### 3.3 자원 역할

| 자원 | 용도 | 처리 |
|---|---|---|
| 식량 | 다음 날까지 생존 유지 | 은신처 전체가 하루 2개 소비 |
| 의약품 | 출발 전 생존자 치료 | 1개로 HP 3 회복, 최대 HP를 넘지 않음 |
| 부품 | 무전기 수리 목표 | 은신처 보유량 8개 이상이면 종료 조건에서 승리 |

식량 소비는 다음처럼 처리한다.

- 2개 이상이면 2개를 차감하고 피해 없이 종료한다.
- 0~1개면 남은 식량을 전부 소비하고, 살아 있는 생존자 전원에게 HP 2 피해를 한 번 적용한다.
- 일부 식량이 있어도 부족 피해를 나누어 줄이지 않는다. 부족량 비례 계산과 개별 배급은 기본판에서 제외한다.
- 생존자 수가 줄어도 일일 소비량은 같다. 인원 감소가 식량 절약으로 이어지지 않도록 한다.

### 3.4 하루 종료 처리 순서

1. 귀환 또는 사망 결과를 확정한다.
2. 살아 돌아왔다면 임시 전리품을 은신처에 반영한다. 사망했다면 임시 전리품을 폐기한다.
3. 전원 사망이면 패배한다.
4. 부품 목표를 달성했다면 수리·구조 요청 후 승리한다.
5. 마지막 날이면 기한 초과로 패배한다.
6. 게임이 계속된다면 식량을 소비하고 부족 피해를 적용한다.
7. 식량 부족 피해로 전원 사망했다면 패배한다.
8. 남은 생존자가 있으면 날짜를 1 증가시키고 다음 날 은신처로 이동한다.

승리·패배가 결정되면 이후 정산은 실행하지 않는다. 따라서 7일째 승리하는 경우 식량 소비는 앞선 6일에만 발생한다.

## 4. 외부 탐색 시스템

### 4.1 단계와 행동 순서

한 번의 탐색은 최대 5단계다. 각 단계에서 다음 순서를 한 번씩 실행한다.

```text
단계 진입
    ↓
[내부 비공개] 사건 없음 / 기회 사건 / 위험 사건 결정
    ↓
사건이 있으면 상황 표시 → 즉시 결과 또는 선택·주사위 판정 → 결과 확인
    ↓
생존했다면 수색하기 / 수색 생략
    ├─ 수색하기 → D20 연출 → 전리품 결과 확인
    └─ 수색 생략 → 보상 없이 진행
    ↓
1~4단계: 다음 단계 / 귀환
5단계: 귀환 절차
```

- 사건 처리 중에는 수색·다음 단계·일반 귀환 버튼을 사용할 수 없다. 이미 만난 위험 사건은 처리해야 한다.
- 사건을 해결한 뒤에는 수색을 생략할 수 있다. 생략 후 귀환하거나 다음 단계로 갈 수 있다.
- 생략하거나 수색한 단계로 돌아가 다시 수색할 수 없다.
- 무료 수색은 보상을 기대하는 기본 조작이다. 생략에 별도 이익을 주거나 전략적 선택으로 강조하지 않는다.
- 마지막 단계에서도 수색 또는 생략을 먼저 처리한다. 결과 확인 후 귀환으로 넘어가며 6단계 진입은 없다.
- 사건 결과로 사망하면 이후 흐름을 중단한다. 살아 있다면 사건 보상 유무와 관계없이 일반 수색 기회가 남는다.

### 4.2 일반 수색

- 플레이어가 `수색하기`를 한 번 누르면 공정한 D20 하나를 굴린다. 별도 `굴리기` 확인은 없다.
- 능력치 보정, 재굴림, 수색 자체의 HP·자원·소음 비용은 없다.
- 연출 중 추가 입력으로 판정이 중복되지 않도록 한다. 결과는 한 번만 적용한다.
- 수색 결과는 사건 발생이나 사건 행동의 성공·실패와 별도로 결정한다.
- 기본판의 높은 눈 보상은 기존 자원을 더 많이 받는 것이다. 별도 희귀 아이템 시스템은 만들지 않는다.

**초기 수색 보상 표 — 지역 주 자원 획득량**

| D20 | 결과 | 1~2단계 | 3~4단계 | 5단계 |
|---|---|---:|---:|---:|
| 1~6 | 미발견 | 0 | 0 | 0 |
| 7~15 | 일반 발견 | 1 | 1 | 1 |
| 16~19 | 좋은 발견 | 2 | 3 | 4 |
| 20 | 대박 발견 | 3 | 4 | 5 |

깊은 단계에서도 실패는 발생한다. 깊이에 따라 성공 자체를 보장하지 않고, 높은 눈이 나왔을 때의 보상을 늘린다. **현재 기본판의 일반 수색**에서는 마트에서 식량, 병원에서 의약품, 창고에서 부품을 얻는다. 한 번의 수색에서 한 종류만 나온다는 것은 초기 콘텐츠 설정이며, 확장 후에도 강제할 공통 규칙은 아니다.

**보상 확장 기준**

- 수색 결과는 식량·의약품·부품별 수량을 가진 하나의 보상 묶음으로 취급한다. 미발견은 모두 0, 단일 보상은 한 종류만 양수, 복수 보상은 여러 종류가 양수인 경우다.
- D20 한 번의 결과로 현재 지역·단계에 적용할 보상 묶음을 결정한다. 복수 자원을 지급해도 자원마다 주사위를 추가로 굴리지 않는다.
- 기본판 데이터는 위 표의 수량을 주 자원 하나에만 넣는다. 전리품 반영, 결과 UI, 귀환 정산은 처음부터 묶음 전체를 처리한다.
- 확장 시 지역별 보상표를 설정할 수 있다. 별도 표가 없는 지역은 공통 기본표를 사용하며, 표를 바꾸어도 수색 진행 순서는 같다.
- 주 자원은 해당 지역을 방문할 목적을 설명한다. 부수 자원을 넣더라도 지역마다 비슷한 자원 구성을 주는 방향은 피하고, 필요한 자원을 구할 장소의 차이를 유지한다.
- 현재 자원 세 종류를 섞는 확장과 장비·새 자원 종류를 추가하는 확장은 구분한다. 후자는 별도 규칙 검토가 필요하다.

| 결과 표현 예시 | 식량 | 의약품 | 부품 |
|---|---:|---:|---:|
| 미발견 | 0 | 0 | 0 |
| 단일 보상 | 2 | 0 | 0 |
| 복수 보상 | 2 | 1 | 0 |

위 표는 표현 방식의 예시이며 실제 수색 확률표가 아니다. 향후 마트의 구급상자에서 의약품을, 병원의 비상 보관함에서 식량을 발견하는 식으로 확장할 수 있다. 혼합 비율과 지급량은 아직 정하지 않았으며, 현재 기본판의 보상량·주사위 구간에는 반영하지 않는다.

### 4.3 사건 발생과 추첨

- 단계 진입 시 아래 세 범주 중 하나를 내부에서 추첨한다. 범주별 확률의 합은 100%다.
- `사건 없음`이면 수색으로 진행한다. 다른 범주이면 해당 지역·단계에서 사용 가능한 사건 하나를 뽑는다.
- **기회 사건:** 무조건 보상을 얻거나, 원하면 위험을 감수하고 추가 보상을 노리는 사건. 도전 선택에 실패하면 피해가 생길 수 있다.
- **위험 사건:** 이미 마주친 위협으로, 판정 등 대응을 끝내야 수색이나 귀환을 할 수 있는 사건.
- `즉시 결과형 / 판정형 / 선택형`은 처리 방식이고, `기회 / 위험`은 추첨 범주다. 서로 다른 분류로 관리한다.

**초기 단계별 범주 확률**

| 단계 | 사건 없음 | 기회 사건 | 위험 사건 |
|---|---:|---:|---:|
| 1 | 65% | 20% | 15% |
| 2 | 55% | 20% | 25% |
| 3 | 45% | 20% | 35% |
| 4 | 35% | 20% | 45% |
| 5 | 25% | 20% | 55% |

깊어질수록 **강제로 대응해야 하는 위험 사건의 빈도**가 높아진다. 긍정적 사건까지 포함한 전체 사건 발생률만으로 위험을 표현하지 않는다.

범주 안에서는 사용 가능한 사건을 같은 확률로 뽑는다. 한 번의 탐색에서 직전 단계에 나온 사건과 같은 사건은 다른 후보가 있을 때 제외한다. 대체 후보가 없다면 중복을 허용하고, 다른 날에는 다시 등장할 수 있다. 해당 범주의 후보가 하나도 없으면 사건 없이 진행하되, 콘텐츠 검토에서 누락으로 확인한다. 기본판 지역은 기회·위험 사건을 모두 갖춰야 한다.

발생 판정값과 뽑히지 않은 사건 목록은 플레이어에게 보여주지 않는다. 현재 단계의 위험 수준과 다음 단계의 예상 보상·위험은 보여준다.

### 4.4 사건 처리 방식

| 처리 방식 | 기본 흐름 | 예시 |
|---|---|---|
| 즉시 결과형 | 상황 표시 → 효과 적용 → 결과 확인 | 버려진 물자 획득 |
| 판정형 | 상황·성공 조건 표시 → 대응 버튼 → D20 → 결과 | 접근하는 좀비 돌파 |
| 선택형 | 상황·선택별 대가 표시 → 행동 선택 → 필요 시 D20 → 결과 | 잠긴 보관함을 열거나 포기 |

- 즉시 결과형에 의미 없는 획득/무시 선택지를 붙이지 않는다. 결과 확인 버튼만 둔다.
- 판정형은 한 가지 대응만 있어도 된다. 모든 사건에 여러 선택지를 강제하지 않는다.
- 선택형은 기본적으로 2개, 필요한 경우 최대 3개의 행동으로 제한한다.
- 판정 행동 버튼을 누르면 해당 주사위를 바로 굴린다. 일반 수색과 같은 연출을 사용한다.
- 사건의 비용, 성공·실패 효과는 선택 전에 표시하고, 실제 효과는 결과에서 한 번만 적용한다.

### 4.5 행동 판정

```text
D20 + 지정 능력치 보정 >= 난이도(DC) → 성공
그 외 → 실패
```

- 전투·기술 중 하나 또는 보정 없는 D20을 사건 행동에 지정한다. 일반 수색에는 적용하지 않는다.
- 눈 1과 20의 별도 치명적 실패·자동 성공 규칙은 없다. 위 공식만 사용한다.
- 판정 전에 적용 능력치, DC, 성공·실패 효과를 표시한다.
- 결과에는 원래 주사위 눈, 능력치 보정, 합계, 성공 여부를 보여준다.

### 4.6 추가 탐색과 귀환

- 다음 단계에 들어가면 새로운 사건 위험에 노출된다. 이미 확보한 전리품도 사망하면 잃는다.
- 현재 HP, 전리품, 소음과 귀환 위험을 보고 계속할지 판단한다.
- 귀환은 안전을 무조건 보장하는 버튼이 아니다. 현재 소음에 따른 절차를 거쳐야 한다.
- 소음이 최대여도 다음 단계의 HP 손실 위험은 남는다. 다만 최대 소음에서 끝까지 진행하는 것이 지나치게 유리한지는 플레이로 확인한다.

## 5. 소음 및 귀환 위험

### 5.1 소음 누적

- 출발할 때 소음은 0이며 사건 행동과 결과에 따라 증가한다. 최대 6까지만 반영한다.
- 일반 수색과 단계 이동만으로 소음이 증가하지는 않는다. 기본판에는 소음 감소 행동이 없다.
- 높은 소음 자체로 즉사하거나 강제 귀환하지 않는다.
- 귀환·사망으로 해당 탐색이 끝나면 소음은 다음 날에 이월하지 않는다.
- 총기 사용과 같은 전용 장비 행동은 현재 사건에 포함하지 않으며, 장비 규칙이 추가될 때 검토한다.

### 5.2 귀환 절차와 초기 수치

| 소음 | 표시 | 위험 사건 발생 확률 | 사건 실패 시 피해 |
|---|---|---:|---:|
| 0~2 | 안전 | 0% | 없음 |
| 3 | 주의 | 30% | HP -2 |
| 4 | 위험 | 50% | HP -2 |
| 5 | 매우 위험 | 75% | HP -3 |
| 6 | 위험 확정 | 100% | HP -3 |

1. 귀환을 시작하면 더 탐색할 수 없다.
2. 현재 소음을 기준으로 위험 사건 발생 여부를 한 번 판정한다. 소음 0~2는 판정 연출 없이 안전 귀환한다.
3. 사건이 없으면 귀환 성공이다. 발생하면 귀환 전용 사건을 한 번 처리한다.
4. 사건 성공이면 피해 없이 귀환한다. 실패하면 표의 피해를 적용한다.
5. HP가 남으면 전리품 전체를 가지고 귀환한다. HP가 0이면 사망하여 임시 전리품 전체를 잃는다.

귀환 사건에서 추가 소음이나 또 다른 귀환 사건을 연쇄 발생시키지 않는다. 소음 6은 **사건 발생 확정**이며 실패·사망 확정이 아니다.

기본 귀환 사건은 `RETURN_001 — 돌아오는 길의 좀비 무리`이며, 전투 D20 + 보정으로 DC 12를 판정한다. 기술형 생존자는 탐색 사건에서 소음을 줄여 귀환 위험을 피하기 쉽고, 전투형 생존자는 위험이 발생했을 때 대응하기 쉬운 방향이다. 실제 유불리는 검증 전이다.

### 5.3 플레이어에게 보여줄 정보

- 현재 소음, 위험 등급, 귀환 사건 발생 확률.
- 귀환 사건의 판정 조건과 실패 피해. 실패 피해량이 현재 HP 이상이면 사망 가능성을 표시한다.
- 소음을 발생시키는 선택은 행동 전에 성공·실패 각각의 증가량을 표시한다.
- 내부 발생 판정의 눈은 숨긴다. **사건 발생 확률과 행동 성공 확률을 혼동하게 표시하지 않는다.**

## 6. 생존자 및 지역

### 6.1 초기 생존자

| 인물(임시) | 최대 / 시작 HP | 전투 | 기술 | 기본 역할 |
|---|---:|---:|---:|---|
| 마커스(전직 군인) | 10 / 10 | +4 | +0 | 좀비 조우와 귀환 위험 대응 |
| 사라(정비공) | 8 / 8 | +1 | +4 | 잠금·장치 사건 대응 |

- 둘 다 처음부터 선택할 수 있다. 대기 생존자는 탐색 보상을 만들거나 자동 회복하지 않는다.
- HP는 탐색과 날짜가 끝나도 유지된다. 치료와 명시된 사건 효과가 있을 때만 회복한다.
- 수색 보상은 두 생존자 모두 같은 주사위 표를 사용한다.
- 기본판에는 성장·레벨·피로·장비·고유 스킬이 없다. 생존자를 추가할 때는 우선 같은 능력치와 규칙 안에서 구성한다.

### 6.2 초기 지역

| 지역 | 주 자원 | 기회 사건 | 위험 사건 |
|---|---|---|---|
| 버려진 마트 | 식량 | EVENT_001, EVENT_003, EVENT_005 | EVENT_002 |
| 폐쇄된 병원 | 의약품 | EVENT_001, EVENT_003, EVENT_005 | EVENT_002, EVENT_004 |
| 공업 창고 | 부품 | EVENT_001, EVENT_003, EVENT_005 | EVENT_002, EVENT_004 |

- 기본판에서는 세 지역 모두 처음부터 열려 있으며, 반복 방문할 수 있다. 자원 고갈과 지역 해금은 없다.
- 기본판은 단계 수, 수색 보상 표, 범주 확률, 귀환 규칙을 공통으로 사용한다. 주 자원과 그림·설명·사건 목록을 바꾼다. 확장 시에는 4.2의 기준으로 지역별 수색 보상표를 지정할 수 있다.
- 마트의 위험 사건 종류는 적지만 발생 확률이 더 낮은 것은 아니다. 지역별 난이도 차이는 검증 후 추가할 수 있으며 현재 보장하지 않는다.
- 지역별 전용 맵 이동이나 별도 진행 시스템은 만들지 않는다.

## 7. 대표 이벤트와 결과

아래는 **첫 구현용 콘텐츠 정의**다. 수치와 문구는 테스트 후 조정한다. 모든 일반 사건은 1~5단계에서 사용하며, 보상은 별도 표기 없으면 지역 주 자원이다. 사건 보상도 임시 전리품에 들어간다.

### EVENT_001 — 잠긴 보관함

- **범주 / 처리:** 기회 / 선택형
- **상황:** 잠긴 보관함 안에서 쓸 만한 물자가 보인다.

| 행동 | 판정 | 성공 결과 | 실패 결과 |
|---|---|---|---|
| 자물쇠 해제 | 기술 D20, DC 14 | 주 자원 +2 | 소음 +1 |
| 강제로 개방 | 전투 D20, DC 11 | 주 자원 +2, 소음 +2 | HP -2, 소음 +2 |
| 지나친다 | 없음 | 효과 없음 | 해당 없음 |

한 행동만 고를 수 있다. 실패한 뒤 다른 행동으로 다시 시도하지 않는다. 결과 확인 후 살아 있으면 일반 수색으로 진행한다.

### EVENT_002 — 배회하는 좀비

- **범주 / 처리:** 위험 / 판정형
- **상황:** 돌아서기 전에 좀비가 접근했다. 길을 확보해야 한다.
- **행동:** `돌파한다` → 전투 D20, DC 12.
- **성공:** HP 손실 없이 통과, 소음 +1.
- **실패:** HP -3, 소음 +2. 살아 있으면 통과한다.
- 사건 보상은 없으며, 생존 시 일반 수색으로 이어진다.

### EVENT_003 — 버려진 물자

- **범주 / 처리:** 기회 / 즉시 결과형
- **상황:** 주인이 떠난 짐에서 쓸 만한 물자를 발견했다.
- **효과:** 지역 주 자원 +1, HP·소음 변화 없음.
- 획득 여부를 묻지 않는다. 획득 결과 확인 후 일반 수색으로 진행한다.

### EVENT_004 — 고장 난 차단문

- **범주 / 처리:** 위험 / 판정형
- **상황:** 진입한 통로의 차단문이 내려왔다. 제어 장치를 조작해야 한다.
- **행동:** `제어 장치를 조작한다` → 기술 D20, DC 12.
- **성공:** 피해·소음 없이 빠져나온다.
- **실패:** 억지로 빠져나오며 HP -2, 소음 +1. 살아 있으면 통과한다.
- 사건 보상은 없으며, 생존 시 일반 수색으로 이어진다.

### EVENT_005 — 무너질 듯한 선반

- **범주 / 처리:** 기회 / 선택형
- **상황:** 불안정한 선반 위에 물자가 남아 있다. 건드리면 무너질 수도 있다.

| 행동 | 판정 | 성공 결과 | 실패 결과 |
|---|---|---|---|
| 물자를 꺼낸다 | 보정 없는 D20, DC 13 | 주 자원 +3 | HP -1, 소음 +2 |
| 지나친다 | 없음 | 효과 없음 | 해당 없음 |

현재 능력치와 무관한 운 중심 보상 기회다. 재시도는 없으며, 생존 시 일반 수색으로 진행한다.

### RETURN_001 — 돌아오는 길의 좀비 무리

- **사용 위치 / 처리:** 귀환 전용 / 판정형. 일반 단계 추첨에서는 제외한다.
- **상황:** 소리를 따라온 좀비들이 은신처로 돌아가는 길을 막았다.
- **행동:** `길을 뚫는다` → 전투 D20, DC 12.
- **성공:** 피해 없이 귀환한다.
- **실패:** 5.2의 현재 소음별 피해를 적용한다. 생존하면 귀환하고, 사망하면 전리품을 잃는다.
- 추가 보상·소음·재추첨은 없다.

## 8. 진행 예시 및 경계 상황

### 8.1 일반 탐색 예시

다음은 위 규칙을 설명하는 가상 결과이며, 고정 이벤트 순서가 아니다.

**출발:** 3일 차, 사라 HP 8, 은신처 부품 3개. 공업 창고 출발, 소음 0.

1. **1단계:** 사건 없음. 수색 D20 = 4 → 획득 없음. 계속 탐색한다.
2. **2단계:** EVENT_003 발생 → 임시 부품 +1. 수색 D20 = 15 → 부품 +1. 누적 임시 부품 2개.
3. **3단계:** EVENT_001에서 강제 개방 선택. D20 = 12, 전투 +1, 합계 13으로 DC 11 성공 → 부품 +2, 소음 +2. 수색 D20 = 17 → 부품 +3. 누적 임시 부품 7개.
4. 은신처 부품 3개와 합치면 목표를 넘는다. 현재 소음 2는 안전이므로 귀환한다.
5. 귀환 사건 없이 임시 부품 7개를 반영한다. 은신처 부품 10개가 되어 구조 요청 후 승리한다. 식량 소비와 다음 날 진행은 하지 않는다.

같은 상황에서 더 탐색하면 추가 물자는 얻을 수 있지만 이미 달성 가능한 승리를 잃을 위험도 있다. 목표를 확보한 뒤까지 추가 탐색을 강요하지 않는다.

### 8.2 위험 귀환 예시

- 마커스 HP 3, 소음 5, 임시 전리품을 가지고 귀환한다.
- 귀환 사건 발생 확률은 75%다. 내부 판정 결과 사건이 발생했다고 가정한다.
- 전투 D20 = 7, 보정 +4 → 합계 11로 DC 12 실패.
- HP 3 피해로 사망하고 해당 탐색 전리품을 잃는다. 다른 생존자가 남아 있다면 날짜와 식량 정산 결과에 따라 게임을 계속한다.
- 같은 상황에서 눈이 8이면 합계 12로 성공하여 피해 없이 전리품을 가져온다.

### 8.3 반드시 일치해야 하는 예외 처리

| 상황 | 처리 |
|---|---|
| 사건 처리 중 HP 0 | 즉시 사망, 수색·귀환 판정 없음 |
| 5단계 수색 또는 생략 완료 | 다음 단계 버튼 없이 귀환 절차 |
| 소음 2에서 귀환 | 위험 사건 없음 |
| 소음 6에서 귀환 | 사건은 반드시 발생하지만 행동 판정은 별도 |
| 귀환 실패 피해를 받고 HP 1 이상 | 전리품 전체 반영 |
| 마지막 날 목표 부품 확보 후 귀환 | 기한 패배보다 승리 판정 우선 |
| 마지막 날 목표 미달 | 식량 소비 전 기한 패배 |
| 식량 부족으로 전원 HP 0 | 다음 날 이동 전 패배 |
| 최대 HP인 생존자 치료 시도 | 사용 불가, 의약품 차감 없음 |
| 주사위 연출 중 버튼 연타 | 추가 판정·보상·피해 중복 적용 없음 |

## 9. UI/UX 콘셉트

### 9.1 화면 구성

PC 가로형 16:9, 어두운 좀비 아포칼립스와 낡은 생존 기록 분위기를 사용한다.

| 화면 | 표시와 조작 |
|---|---|
| 은신처 | 날짜/남은 탐색 기회, 부품 목표, 보유 자원, 일일 식량 소비, 생존자 HP·능력치, 치료, 지역 선택, 출발 |
| 탐색 | 왼쪽 지역 일러스트, 오른쪽 상황·행동, 상단 HP·전리품·소음, 하단 단계·수색·다음 단계·귀환 |
| 공통 주사위 영역 | 눈, 능력치 보정, 합계/DC, 성공 또는 획득량 |
| 정산 패널 | 확보/상실한 전리품, 생존자 상태, 식량 소비·부족 피해, 다음 날 |
| 종료 패널 | 구조 성공 또는 패배 사유, 최종 생존자·부품·날짜, 새 게임 |

정산과 종료는 별도 대형 화면 대신 공통 패널로 구성할 수 있다. 새 게임은 날짜·인물·자원을 초기값으로 되돌린다.

### 9.2 조작과 피드백

- 수색과 판정 행동은 버튼 한 번으로 굴린다. 결과 확인은 한 번으로 끝낸다.
- 사건 처리, 주사위 연출, 정산 중에는 충돌하는 버튼을 비활성화한다.
- 획득량, HP 감소, 소음 증가를 각각 표시하여 무엇이 바뀌었는지 알 수 있게 한다.
- 보상은 양수인 자원 종류를 모두 아이콘과 수량으로 표시한다. 여러 종류를 동시에 얻어도 하나의 결과 화면에서 확인하며, 모든 자원이 0일 때만 미발견으로 표시한다. 지역 주 자원 하나만 표시하도록 고정하지 않는다.
- 귀환 버튼 근처에 현재 위험 등급·발생 확률·실패 피해를 표시한다.
- 다음 단계 버튼 근처에 다음 단계의 보상 표와 위험 사건 확률을 확인할 수 있게 한다. 수치를 화면 전체에 항상 펼쳐 놓을 필요는 없다.
- 내부 사건 발생 주사위는 연출하지 않는다. 플레이어가 굴리는 수색·행동 주사위에 연출을 집중한다.
- 주사위 연출은 짧게 유지한다. 결과가 정해진 뒤 연출만 건너뛰는 기능은 개선 후보이며, 재굴림과 구분한다.

### 9.3 제작 리소스

- 첫 탐색 시제품은 은신처 배경 1장과 지역 배경 1장으로 시작한다.
- 기본 완성본은 은신처 1장, 지역 3장, 생존자 초상화 2장, 자원 아이콘 3종, 공통 버튼·주사위·결과 표현을 사용한다.
- 개별 사건마다 전용 일러스트를 만들지 않는다. 같은 배경 위의 상황 텍스트와 결과 표현을 바꾼다.

기존 시각·진행 참고작은 *Roadwarden*, *Choice of Life: Middle Ages*, *Citizen Sleeper*, *60 Seconds! Reatomized*다. 전체 규칙을 복제하는 기준이 아니라 일러스트·텍스트 배치, 결과 확인 리듬, 주사위 표현, 하루 단위 진행을 살펴볼 참고 후보로 유지한다.

## 10. 제작 범위와 확장 원칙

### 10.1 첫 탐색 시제품

**목표:** 한 번 출발해 수색·사건·귀환 또는 사망·전리품 정산까지 직접 플레이한다.

| 항목 | 범위 |
|---|---|
| 지역 / 생존자 | 1개 / 1명 |
| 단계 | 최대 5단계 |
| 일반 사건 | EVENT_001~003: 선택형·판정형·즉시 결과형 각 1개 |
| 귀환 사건 | RETURN_001 1개 |
| 화면 | 최소 은신처, 탐색, 주사위, 정산 |
| 확인할 경험 | 보상 기대감, 운에 따른 변화, 계속 탐색/귀환, 결과 이해 |

이 단계는 첫 탐색의 작동을 보는 시제품이며, 다일 생존과 엔딩을 갖춘 완성본으로 표현하지 않는다. 콘텐츠 수를 늘리기 전에 세 처리 방식과 귀환을 확인한다.

### 10.2 기본 완성본

| 항목 | 범위 |
|---|---|
| 진행 | 새 게임 → 최대 7일 → 승리·패배 → 재시작 |
| 지역 / 생존자 | 3개 / 2명 |
| 일반 사건 | 공통 5개(EVENT_001~005)를 지역에 맞게 재사용 |
| 귀환 사건 | 1개(RETURN_001) |
| 자원 | 식량 / 의약품 / 부품 |
| 시스템 | 치료, 식량 소비, 부족 피해, 사망, 목표 판정 |
| 표현 | 실제 결과와 일치하는 위험 안내, 주사위·보상·피해 피드백 |

완료 기준은 다음과 같다.

- 새 게임부터 승리와 두 패배 사유(전원 사망·기한 초과)까지 흐름이 끊기지 않는다.
- 8.3의 경계 상황이 규칙대로 처리되고, 재시작 시 이전 게임 상태가 남지 않는다.
- 지역과 생존자를 바꿔도 같은 진행 구조로 플레이할 수 있다.
- 실제 플레이 기록으로 규칙·UI·밸런스 문제를 구분해 설명할 수 있다.

첫 기본판은 한 세션에서 끝내는 플레이를 기준으로 한다. 중도 종료 시 진행 복원은 보장하지 않으며, 게임 시작 전에 안내한다. 저장·불러오기는 후속 편의 기능 후보로 둔다.

### 10.3 콘텐츠 확장

기본 규칙 안에서 다음을 추가한다.

- 지역: 배경, 설명, 주 자원, 선택적인 지역별 수색 보상표, 기존 규칙으로 처리 가능한 사건 목록.
- 수색 보상: 기존 세 자원으로 구성한 단일·복수 보상 묶음. 수색·전리품·정산 흐름을 교체하지 않고 보상 구성을 변경한다.
- 사건: 상황, 처리 방식, 조건, 선택지, DC, 능력치, 결과 효과.
- 생존자: 이름, 초상화, 최대 HP, 전투·기술 보정.
- 귀환 사건: 귀환 한 번으로 종료되는 공통 절차를 지키는 다른 상황과 판정.

일반 사건 10~20개는 기본 완성본 이후의 확장 목표 후보로 이동한다. 새로운 이름만 붙인 같은 결과를 늘리기보다 반복 경험과 선택의 차이를 보고 추가한다.

**콘텐츠가 가져야 할 정보**

| 콘텐츠 | 기본 정보 |
|---|---|
| 지역 | 고유 ID, 이름·설명·배경, 주 자원, 선택적 수색 보상표, 사용 사건 ID 목록 |
| 수색 보상표 | 단계·D20 구간별 보상 항목 목록. 항목은 지역 주 자원 또는 특정 자원의 종류·수량 |
| 생존자 | 고유 ID, 이름·초상화, 최대 HP, 전투·기술 |
| 일반 사건 | 고유 ID, 기회/위험 범주, 처리 방식, 등장 단계, 상황 텍스트, 행동·결과 |
| 판정 행동 | 이름, 적용 보정, DC, 성공 효과, 실패 효과 |
| 효과 | 하나 이상의 자원 증감 항목, HP 증감량, 소음 증감량 |
| 공통 규칙 | 일수, 단계 수, 초기 자원, 수색 표, 범주 확률, 귀환 표, 식량·치료 수치 |

기본 콘텐츠에서 사용하는 효과만 우선 지원한다. 조건식 편집기, 임의 스크립트 실행, 복잡한 연쇄 사건 도구는 만들지 않는다. 사용하지 않는 고급 조건을 미리 구현하지 않는다.

콘텐츠를 추가할 때에는 ID 중복, 잘못된 사건 참조, 범주별 후보 누락, 누락된 결과, 사용할 수 없는 자원·능력치를 확인한다. 정의된 콘텐츠 정보와 플레이 중 변하는 HP·전리품·날짜는 구분한다. 구체적인 클래스와 저장 방식은 코드 설계 단계에서 결정한다.

### 10.4 규칙 확장 후보

| 후보 | 추가되는 규칙 | 검토 시점 |
|---|---|---|
| 장비·소모 도구 | 획득, 보유, 사용 시점, 판정 변화 | 기본판에서 행동의 변화를 더 주고 싶을 때 |
| 생존자 고유 특성 | 특정 조건의 보정·효과 | 기존 능력치만으로 인물 차이가 부족할 때 |
| 제한된 재굴림 | 사용 자원, 사용 시점, 이전 결과 처리 | 운에 개입할 기회가 필요한지 확인한 뒤 |
| 새로운 목표·게임 모드 | 승패 조건, 날짜·자원 흐름 | 기본 제한 시간 모드가 완성된 뒤 |
| 저장·불러오기 | 저장 시점, 복원 범위, 버전 대응 | 실제 플레이 길이와 중단 필요를 확인한 뒤 |

위 후보는 승인된 제작 목록이 아니다. 어떤 문제를 해결하는지, 운 중심 경험을 해치지 않는지, 기존 진행과 어떤 충돌이 있는지 판단한 뒤 하나씩 추가한다.

### 10.5 기본판 제외 범위

3D 월드, 캐릭터 이동, 실시간 전투, 좀비 AI, 지역별 맵, 다인 파티, 시설 건설, 제작 트리, 관계·성장 시스템, 장기 서사 분기, 대규모 개별 삽화, 여러 모드·엔딩은 기본판에 포함하지 않는다. 범용 프레임워크 제작 자체를 포트폴리오 목표로 삼지 않는다.

## 11. 검증과 후속 결정

### 11.1 현재 정한 것과 남은 것

- **첫 구현 기준으로 정한 것:** 사건 판정 시점, 단계 행동, 수색 보정 여부, 귀환 종료 방식, 사망·전리품, 식량 소비 방식, 하루 정산 순서, 대표 사건.
- **플레이 후 조정할 것:** 제한 일수, 초기 자원, 부품 목표, 보상량, 범주 확률, 소음별 위험, HP·DC·피해량, 사건 반복 빈도.
- **아직 구현하지 않을 것:** 10.4의 새로운 규칙과 편의 기능 후보.

### 11.2 첫 플레이에서 확인할 질문

1. 수색 버튼을 반복해서 눌러도 다음 결과가 기대되는가? 연출·확인이 지루하게 늘어지지 않는가?
2. HP가 충분하고 전리품이 적을 때, HP가 낮고 목표 부품을 확보했을 때의 진행 선택이 달라지는가?
3. 최대 소음에서 계속 진행하는 선택이 항상 유리하게 느껴지는가? 다음 단계의 체력 위험이 실제로 작동하는가?
4. 실패했을 때 위험을 감수한 이유와 잃은 자원을 이해할 수 있는가? 귀환 확률을 사망 확률로 오해하지 않는가?
5. 마트·병원 방문이 필요한가? 창고 반복 방문만으로 지나치게 쉽게 끝나거나, 식량 확보에만 끌려다니지 않는가?
6. 생존자를 바꿀 이유가 있는가? 한 명의 사망이 소비 절약이라는 이득으로 작동하지 않는가?
7. 같은 사건의 반복이 거슬리기 전에 한 판이 끝나는가? 부족하다면 어떤 사건 유형부터 추가해야 하는가?

전략적 정답을 많이 만드는 것이 검증 목표는 아니다. 운의 변화가 기대·긴장·안도감을 주는지, 최소한의 선택이 이해되는지를 우선한다.

### 11.3 자원 수치의 출발점

공정한 D20과 4.2의 **초기 단일 자원 보상 표**를 가정하면 사건 보상·사망 손실을 제외한 수색 기대 획득량은 다음과 같다.

| 구간 | 수색 1회 기대량 |
|---|---:|
| 1~2단계 | 1개 |
| 3~4단계 | 1.25개 |
| 5단계 | 1.5개 |

5단계를 모두 수색하면 주 자원 기대량은 6개다. 7일째까지 진행할 경우 마지막 날 이전 식량 소비는 12개이며 초기 식량은 6개다. 그러나 사건 보상, 조기 귀환, 치료, 사망, 조기 승리에 따라 실제 수급은 달라진다.

부품 8개는 창고 탐색 몇 번으로 빠르게 달성될 수도 있는 초기값이다. 7일을 반드시 채우게 만들지는 않는다. 실제 완료 일수, 승패 사유, 귀환 단계·소음·HP, 자원 부족 빈도를 확인하고 목표량과 수급을 함께 조정한다. 이 계산만으로 밸런스가 검증되었다고 판단하지 않는다.

복수 자원 보상을 도입하면 자원별 기대 획득량을 따로 다시 계산한다. 부수 식량·의약품이 다른 지역 방문 필요를 없애거나, 창고 반복 방문만으로 생존과 승리를 모두 해결하게 되는지 확인한다. 총 지급 개수만 비교하지 않고 식량 소비, 치료 효율, 부품 목표를 함께 조정한다. 개발용 복수 보상 예시로 처리 경로를 확인하는 것과 실제 기본판의 수급을 바꾸는 것은 구분한다.

### 11.4 확인 수준의 구분

- 문서 검토: 표·예시·처리 순서의 일치와 규칙 누락을 확인한다.
- 구현 검증: 경계 상황, 입력 중복, 보상·피해 적용, 재시작을 실제 구현에서 확인한다.
- 플레이 검증: 운의 재미, 피로도, 선택, 난이도와 반복성을 실제로 확인한다.

v0.3 작성은 문서 수준의 구체화이며, 컴파일·실행·플레이 검증을 수행했다는 의미가 아니다.
